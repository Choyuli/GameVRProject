## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **건 타이쿤** |
| 장르 | TPS / Action / Tycoon |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | Third Person |
| 예상 플레이 시간 | 10~15분 |

### 한 줄 소개
> 던전에서 나오는 몬스터를 잡고 나오는 재화로 용병,건물,무기 등을 구매하여 돈을 버는 타이쿤류 게임.

## 2. 게임 컨셉


### 핵심 키워드

- **Build** : 무기 업그레이드나 돈을 벌기 위한 시설 건설 
- **Combat** : 적과의 전투
- **Collect** : 재화를 모은다
- **upgrade** : 성장하여 더 빠르게 돈을 번다

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
탐색
  ↓
적 발견
  ↓
조준 및 사격
  ↓
적 처치
  ↓
아이템 / 탄약 획득
  ↓
다음 구역 이동
  ↓
보안카드 획득
  ↓
탈출
```

플레이어는 게임이 종료될 때까지 **탐색 → 전투 → 아이템 획득 → 이동**의 과정을 반복한다.

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Left Click | 총 발사 |
| Right Click | 조준 |
| Space | 점프 |
| Shift | 달리기 |
| R | 재장전 |
| E | 아이템 획득 / 문 상호작용 |

## 6. 플레이어 기능

### 6.1 이동

플레이어는 FPS 방식으로 맵 내부를 자유롭게 이동할 수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 점프
- 달리기
