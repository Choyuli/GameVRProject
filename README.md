# GameVRProject
Tycoon

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **건 타이쿤** |
| 장르 | TPS / Action / Tycoon |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | Third Person |
| 예상 플레이 시간 | 10~15분 |

### 한 줄 소개
> 던전에서 나오는 몬스터를 잡고 나오는 재화로 용병,건물,무기 등을 구매하여 돈을 버는 타이쿤류 게임.

---

## 2. 게임 컨셉


### 핵심 키워드

- **Build** : 무기 업그레이드나 돈을 벌기 위한 시설 건설 
- **Combat** : 적과의 전투
- **Collect** : 재화를 모은다
- **upgrade** : 성장하여 더 빠르게 돈을 번다 

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.
1.던전에서 몬스터를 처치한다.
2.거기서 얻은 돈을 이용해 건물을 짓는다.
3.건물에서 용병,새 무기등을 구매한다.
4. 더 많은 돈을 번다.
4. 최종 무기를 구매하면 클리어.

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
  ↓
적 사격
  ↓
적 처치
  ↓
재화 흭득
  ↓
건물 구매
  ↓
총기, 용병 구매
  ↓
더 많은 재화 수급
  ↓
최종 무기 구매
```

플레이어는 게임이 종료될 때까지 **전투 → 재화 수급 → 업그레이드**의 과정을 반복한다.

---

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Left Click | 총 발사 / 건물 설치|
| Right Click | 조준 |
| Space | 점프 |
| Shift | 달리기 |
| E | 상호작용 |

---

## 6. 플레이어 기능

### 6.1 이동

플레이어는 TPS 방식으로 맵 내부를 자유롭게 이동할 수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 점프
- 달리기
- 총 발사
- 건물 설치
